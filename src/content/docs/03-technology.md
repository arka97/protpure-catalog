# Technology

Cross-linked agarose backbone with proprietary ligand chemistry.

## Bead architecture

- Mean particle size: 45–165 µm
- Pore distribution optimized for target MW range
- Pressure-flow characteristics validated to 300 cm/h

## Ligand chemistry

- Quaternary ammonium (Q)
- Sulfopropyl (SP)
- Diethylaminoethyl (DEAE)
- Carboxymethyl (CM)

## QC

Every batch is tested for:
- [x] Particle size distribution
- [x] Ionic capacity
- [x] Dynamic binding capacity
- [ ] Long-term storage stability (in development)
